# 汉语助教 HanAssist：国际中文教学 AI 工作台（产品与技术方案）

面向“中国教师教外国学生汉语”场景的 AI 产品方案，单个 HTML 交付，内容包括：

- **逐条回应**：调研中的 13 个痛点，每条给出判断、方案、技术实现和界面。
- **专题**：大模型辅助中文纠音（声调）、权威分级与课件流水线。
- **可交互界面原型**：教师端（工作台、课件生成、资源库、分级检查、课堂游戏、学情报告、记忆中心）和学生端（跟读纠音、汉字书写）。
- **产品落地**：端到端串联（用户旅程泳道）、技术架构、数据与接口、POC 到上市路线、商业化、风险合规与不做清单。

## 打开方式

直接双击 `index.html` 即可，所有资源已内联，离线可用。

麦克风录音（跟读纠音页）需要在 `localhost` 或 https 下打开：

```bash
cd zh-teach-ai
python3 -m http.server 4873 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:4873/
```

没有麦克风时，可点“模拟一段学习者录音”，交替演示典型错误和正确发音。

## 目录结构

```
zh-teach-ai/
├── index.html            # 构建产物（单文件，可直接打开）
├── build.mjs             # 把 src/ 内联成 index.html
└── src/
    ├── body.html         # 方案正文 + 原型界面结构
    ├── styles.css
    ├── app.js            # 原型交互：课件生成、分级检查、游戏、纠音、书写、记忆
    └── vendor/
        ├── hanzi-writer.min.js   # Hanzi Writer 3.7.3（MIT）
        └── hanzi-data.js         # 演示用 12 个字的笔画数据
```

修改 `src/` 后重新生成：

```bash
node zh-teach-ai/build.mjs
```

## 原型说明

- 课件内容、词表、学情和资源库都是演示数据。分级检查只内置了一个小词表，不代表 GF 0025-2021 的完整词表。
- 纠音页在浏览器内用 YIN 基频提取加规则判别声调，只用来演示交互和“音高曲线 + 诊断”的呈现方式。生产方案见文档“专题：中文纠音”：强制对齐、GOP、专用声调模型，先采购商用评测再自研。
- 笔顺数据来自 Make Me a Hanzi（Arphic Public License），通过 hanzi-writer-data 获取；Hanzi Writer 使用 MIT 协议。
